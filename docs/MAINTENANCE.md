# Maintenance du projet PFMP — Var

La base de données du projet est SQLite : `database/entreprises.db`.
Les scripts d'administration et de synchronisation sont exécutés localement depuis le poste de l'enseignant.

Voir le [README](../README.md) pour :
- initialiser la base ;
- ajouter, modifier, masquer ou supprimer une entreprise ;
- lancer la collecte et la synchronisation ;
- exporter les données destinées à GitHub Pages.

La base SQLite est versionnée dans le dépôt GitHub public. Ne pas y enregistrer de données personnelles ou confidentielles.
